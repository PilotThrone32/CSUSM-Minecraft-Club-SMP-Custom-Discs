# CSUSM-Minecraft-Club-SMP-Custom-Discs-Resource-Pack/Datapack
Datapack and Resource Pack for all the custom music discs on the CSUSM SMP S4

Initial version credit: https://juponhuissier.github.io/custom-jukebox/index.html

Assisted by AI for bug testing

How to add to your Minecraft World

Single Player 

1. Download release files

2. Go to the Minecraft Save that you want to add it to (minecraft/saves/[Your World Name])

3. Drag the DP zip file into the datapack folder (if it is missing, you can create a new folder and name it datapacks).

4. Add the RP zip file into your resourcepack folder

5. Enter your Minecraft Save

6. Enable Cheats (open to lan) and do /reload

7. Done!

Server

1. Download release files

2. Go to your server panel

3. Drag the DP zip file into the datapack folder.

4. Add the RP zip file into your resourcepack folder

5. Enter your Minecraft Server

6. Have operator or use server console and run /reload

7. Done!
